# Simple Presenter Guide

## Slide 1 — Proposal

“Ang akong proposal kay dugangan nato og map ang existing Vessel Management. Ang purpose kay makita sa management ang latest reported location sa matag vessel nga adunay active voyage.”

## Slide 2 — Current process

“Dili nato usbon ang existing process. Mag-create gihapon og voyage, add status, add activity, ug complete voyage. Map ug coordinates ra ang idugang.”

## Slide 3 — Create Voyage

“Sa pag-create og voyage, i-plot sa user ang Port Origin, Port Destination, ug initial Current Location. Pwede pinaagi sa search, map pin, mobile GPS, o manual latitude ug longitude.”

## Slide 4 — Movement of the marker

“Kada mag-add og activity ug mag-update sa current location, ang latest coordinates mao ang bag-ong position sa vessel marker. Ang previous positions dili mawala kay naa tay location history.”

## Slide 5 — Management map

“Usa ka map ang magpakita sa tanan vessels nga adunay current voyage. Kung i-click ang marker, makita ang vessel, voyage number, status, origin, destination, ug last update.”

## Slide 6 — Access

“Managers makita ang active fleet. Ang captain assigned vessel ra iyang makita ug ma-update. Ang executive viewer read-only.”

## Slide 7 — Important limitation

“Sa Phase 1, latest reported tracking pa kini. Ang marker molihok kung adunay user nga nag-save og location. Kung gusto nato continuous automatic tracking, kinahanglan puhon og AIS provider o GPS device integration.”

## Slide 8 — Approval request

“Mangayo ta og approval nga himuon una ang Phase 1 prototype ug pilot. Human makita ang actual value, didto ta magdesisyon kung kinahanglan ang full AIS/GPS integration.”
